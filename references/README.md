# Reference inputs not bundled in this candidate

The source working repository is unchanged. No reference data have been copied
here while their publication provenance/permissions are being reviewed.

Required inputs include GRCh38 FASTA/indexes, a genome-wide 5 kb BED, fixed
discovery hyper/hypo DMR intervals, EPIC v2 hg38 probe annotation, the fixed CHIP
CNA coordinate template, Dorado models and ichorCNA GC/map/centromere resources.
Module 19 additionally expects wgbs_discovery_dmrs.bed (the 3995 discovery DMRs).

Before final release, document actual source/release, genome build, coordinate
convention, checksum, terms and retrieval instructions for each reference.
Review which author-derived interval files can be included, as they may be
necessary to reproduce the exact analysis. Do not replace them with arbitrary
new intervals or assume an identically named file is equivalent.
